# Архив оригинального сайта (Tilda)

Снимок `https://online.katkov.school`, сделанный **28 августа 2026 года**, — до
переписывания на Astro. Служит эталоном: копия сверялась именно с ним.

## Как открыть

Откройте `index.html` в браузере — копия полностью автономна: 92 файла
(71 изображение, CSS и JS Tilda) лежат в `assets/`, все ссылки переписаны на
локальные пути, ни одного запроса наружу.

```
old/
├── index.html
└── assets/
    ├── css/   # 6 файлов, включая tilda-blocks-page22741439.min.css
    ├── js/    # 19 файлов Tilda
    └── img/   # 71 изображение
```

Главный CSS Tilda отдаёт не со своего CDN, а с домена самого сайта
(`/tilda-blocks-pageNNNN.min.css`). Без него страница рендерится пустой —
в архиве он есть.

## Отличия от того, что было в сети

- **Аналитика удалена** — `tilda-stat` вырезан, `dns-prefetch` убраны.
- **Форма регистрации не работает** — это виджет GetCourse, он подгружался
  с `katkov.school`. В новой версии виджет подключён и работает.

## Зачем это здесь

Чтобы заявление «копия 1:1» можно было проверить: откройте архив рядом
с новой версией и сравните. Методика сверки и полный список расхождений —
в [корневом README](../README.md).

Папка не участвует в сборке: она вне `src/` и исключена в `tsconfig.json`.
