# online.katkov.school

Лендинг вебинара Павла Каткова «Алгоритм взрывного роста юридического бизнеса».

Это **копия 1:1** оригинального сайта, собранного в Tilda, переписанная на
современном стеке. Оригинал сохранён в [`old/`](./old) как автономная офлайн-копия
и служит эталоном, с которым сверялась вёрстка.

| | |
|---|---|
| **Стек** | [Astro 5](https://astro.build) · TypeScript |
| **Рендеринг** | статическая генерация, ноль фреймворков на клиенте |
| **Что осталось от Tilda** | ничего: ни CSS-фреймворка, ни JS, ни jQuery |
| **Своего JS** | ~3 КБ: анимации, слайдеры, попап, cookie-баннер |

---

## Быстрый старт

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # сборка в dist/
npm run preview  # просмотр собранного
npm run check    # проверка типов
```

## Как это устроено

Оригинал целиком построен на Tilda Zero Block: каждый элемент позиционируется
абсолютно внутри «артборда» фиксированной высоты, со своим набором координат
на каждый из пяти брейкпоинтов (1200 / 960 / 640 / 480 / 320).

Копия воспроизводит ту же модель, но без рантайма Tilda:

```
src/
├── data/
│   ├── blocks.json      # 178 элементов: тип, контент, ссылки, анимация
│   ├── types.ts         # типы модели
│   └── site.ts          # мета, аналитика, тексты баннера
├── styles/
│   ├── base.css         # рантайм артборда (~120 строк) + анимации
│   └── artboards.css    # геометрия всех элементов на 5 брейкпоинтов
├── components/
│   ├── Artboard.astro   # рендерит запись из модели
│   ├── ZeroElement.astro# один элемент: shape / text / image / button / html
│   ├── Gallery.astro    # слайдер (заменяет tilda-zero-gallery)
│   ├── RegPopup.astro   # попап регистрации
│   └── CookieBanner.astro
└── pages/index.astro
```

`artboards.css` — это извлечённая из оригинала геометрия. Она не переписывалась
вручную: это спецификация дизайна, и именно она обеспечивает точность.
Всё остальное — разметка, стили-рантайм, скрипты — написано заново.

### Анимации

56 элементов анимируются при прокрутке — те же четыре сценария, что и в
оригинале, с теми же параметрами:

| Стиль | Элементов | Параметры |
|---|---|---|
| `fadeinup` | 23 | 1 с, сдвиг 100 px |
| `zoomin` | 16 | 1 с, старт со `scale(0.9)` |
| `fadeinleft` | 13 | 1 с, сдвиг 100 px |
| `fadeinright` | 4 | 1 с, сдвиг 100 px |

Реализованы на `IntersectionObserver` + CSS-переходах. Элементы, уже
находящиеся в видимой области, раскрываются синхронно — без ожидания первого
асинхронного колбэка. При `prefers-reduced-motion` анимации выключаются, а без
JS контент виден сразу (скрытие включается только классом `.js`).

### Форма регистрации

Кнопки ведут на `#reg` и открывают попап с виджетом GetCourse
(`katkov.school/pl/lite/widget/script?id=546213`) — тем же, что стоял в
оригинале. Скрипт подгружается только при первом открытии попапа, а не на
загрузке страницы.

## Точность копии

Сверка велась не на глаз: обе страницы открывались в одном браузере, и для
каждого элемента сравнивались `getBoundingClientRect()` и вычисленные стили.

**890 проверок (178 элементов × 5 брейкпоинтов): 94.3 % полное совпадение.**

| Ширина | Расхождений из 178 |
|---|---|
| 1280 px | 3 |
| 960 px | 12 |
| 640 px | 12 |
| 492 px | 12 |
| 375 px | 12 |

Все оставшиеся расхождения — только по высоте бокса (`dH`) у 13 элементов
с иконками и у нескольких текстовых блоков (округление межстрочного
интервала на ±1–3 px). Позиции (`left`, `top`) и ширины совпадают везде
без исключений. Шрифты, кегли, начертания, цвета и выравнивание совпадают.

### Что пришлось чинить по дороге

Tilda досчитывает часть стилей в рантайме, поэтому её CSS сам по себе неполон:

1. **Рамки.** 142 правила задают `border-style: solid` без `border-width`.
   По умолчанию это `medium` (3 px) — то есть +6 px к высоте каждого элемента.
   Рантайм Tilda обнулял это; здесь `border-width: 0` задан явно.
2. **Межстрочный интервал.** Tilda округляла `font-size × line-height` до целых
   пикселей перед отрисовкой: `22px × 1.30` даёт 29 px, а не 28.6 px. Округление
   пересчитывается на каждом брейкпоинте, где меняется кегль.
3. **Сетка на промежуточных ширинах.** Правило `left: calc(50% - grid/2 + N)`
   выписывалось только для тех брейкпоинтов, где у элемента был явный
   переопределённый отступ. Из-за этого, например, логотип между 480 и 639 px
   сохранял сетку 640 и уезжал на `-62px` за экран. Недостающие правила
   достроены для всех пяти сеток.
4. **Сглаживание шрифтов.** Контейнер Tilda остаётся на собственном слое
   композитинга после появления страницы, из-за чего Chrome рисует текст
   с полутоновым сглаживанием вместо субпиксельного. Без этого копия рисует
   те же глифы с цветной каймой.

## Деплой

Как и в соседнем проекте — GitHub Pages через Actions
([`deploy.yml`](./.github/workflows/deploy.yml)):

1. Запушить ветку `main`.
2. **Settings → Pages → Source: GitHub Actions.**

Воркфлоу сам включает нужный источник (`enablement: true`) и подставляет адрес
и базовый путь, так что работает и на project-page, и на своём домене.

Для домена: файл `public/CNAME` с одной строкой и DNS-записи GitHub.

## Аналитика

В оригинале стоят Яндекс.Метрика (`88007628`) и GTM (`GTM-M6LW29X`).
Их идентификаторы вынесены в `src/data/site.ts`, но **счётчики не
подключены** — добавьте их в `Base.astro`, если копия должна собирать
статистику в те же аккаунты.
